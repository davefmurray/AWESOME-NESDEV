# Assets

| File | Use |
|---|---|
| `awesome-nesdev-banner.png` | README banner (dark), 1200×360 |
| `awesome-nesdev-banner-light.png` | README banner (light), 1200×360 |
| `divider.png` | Sprite-strip section divider, 1200×80 |
| `sprites.png` | 8-icon sprite sheet, transparent |
| `social-icon.png` | 1024×1024 square icon / avatar |
| `social-preview.png` | 1280×640 GitHub social preview card |
| `logo-ascii.txt` | Terminal/plain-text wordmark |

The banner is drawn with [Press Start 2P](https://fonts.google.com/specimen/Press+Start+2P) by CodeMan38 (SIL Open Font License 1.1), rendered into a PNG. The artwork is released under the repository's CC0 license; the font keeps its OFL terms.

Palette: NES red `#E43B44`, signal white `#F5F3EE`, gold `#FFCC4D`, CRT cyan `#57D9E8`, deep navy `#0A0E18`.

See [BRAND.md](BRAND.md) for palette, type and usage.
