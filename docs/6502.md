# 6502 assembly: repos and training docs

A learning path first, then the repos worth cloning. Everything here is public and reachable as of October 2026.

## Start here, in this order

1. **[Easy 6502](https://skilldrick.github.io/easy6502/)** — an interactive ebook with an in-browser assembler and simulator. You write real instructions, step them, and finish with a small Snake game. CC BY 4.0. This is the fastest zero-to-readable path.
2. **[Wilson Mines 6502 Primer](https://wilsonminesco.com/6502primer/)** — Garth Wilson's practical primer: memory maps, I/O, addressing, code structure, and the things tutorials skip.
3. **[Obelisk 6502 Guide](https://www.nesdev.org/obelisk-6502-guide/)** + **[Instruction reference](https://www.nesdev.org/wiki/Instruction_reference)** — the reference you keep open while writing code: every official opcode, flag and cycle.
4. **[Nerdy Nights](https://nerdy-nights.nes.science/)** — the classic NES assembly course. Move here once you can read 6502; the NES adds the PPU, APU and mapper layer.

## A practice path that works

1. **Easy 6502** — type every example; do not copy-paste.
2. **Rewrite one example** from memory: 16-bit add, a delay loop, a jump table.
3. **Write a 6502 routine and test it in py65** — assemble with ca65, load the bytes, assert registers/RAM.
4. **Read Nova the Squirrel's source** — find one system (input, camera, collision) and trace it.
5. **Do Nerdy Nights on NES** — PPU init, NMI, controller, sprites.
6. **Read a disassembly you own** — TSB or another game — and annotate a routine in `labels.csv`.

## 6502 vs 65C02 vs 2A03

- **6502**: the original; no `STZ`, no `PHX/PHY`, no bit instructions.
- **65C02**: adds instructions and fixes the `JMP ($xxFF)` page bug; code that uses them will not run on NES.
- **2A03/2A07 (NES)**: 6502 core, **no decimal mode** (`SED` has no effect on `ADC`/`SBC`), APU/PPU on the same die.

## Assembler syntax at a glance

| Thing | ca65 | asm6 | dasm |
|---|---|---|---|
| Origin | linker config / `.segment` | `.org $8000` | `ORG $8000` |
| Byte | `.byte $EA` | `.db $EA` | `.byte $EA` |
| Word | `.word $1234` | `.dw $1234` | `.word $1234` |
| Immediate | `#$10` | `#$10` | `#$10` |
| Comment | `;` | `;` | `;` |
| Include | `.include "file"` | `.include "file"` | `include "file"` |

## Cautions

- **Copyright**: disassemblies and ROM hacks of commercial games are for study of ROMs you own; do not redistribute the ROM.
- **Undocumented opcodes**: stable on real 2A03s, but not on all emulators; avoid them in portable code.
- **Cycle counts**: page crossings and taken branches change timing; a table's base cycle is not the whole story.
