## Summary

There are 8 possible sound loops that get played after the snap: $42, ; PRESEASON song P1 $43, ; PRESEASON song P2 $3C, ; PRO-BOWL song P1 $3D, ; PRO-BOWL song P2 $40, ; SEASON song P1 $41, ; SEASON song P2 $3E, ; PLAYOFF song P1 $3F ; PLAYOFF song P2
