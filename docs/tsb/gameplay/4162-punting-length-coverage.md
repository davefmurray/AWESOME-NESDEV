## Summary

Here's the SET command to use for the additional code that [@partyman6666](https://tecmobowl.org/profile/4690-partyman6666/) unearthed: ``` #Punt coverage boost adjustment #http://tecmobowl.org/forums/topic/4162-shorter-punts-rom-hack/?do=findComment&comment=36038 SET(0x8164,0xE200E300) SET(0x8170,0xE200E300) ```

## Key facts

- Here's the SET command to use for the additional code that [@partyman6666](https://tecmobowl.org/profile/4690-partyman6666/) unearthed:
- SET(0x8164,0xE200E300)
- SET(0x8170,0xE200E300)
- SET (0x29369,0x60)
- note that '60' can be adjusted to different values. Refer to the first post for more information from [@partyman6666](https://tecmobowl.org/profile/4690-partyman6666/)
- For every notch of Kicking Power that a punter has, the ball will travel 1 yard farther than an equivalent kick from a weaker punter.
- The hex address of the punt adjustment is at #29369.
