## Summary

- it goes: SET (0x"LOCATION to put code", 0x"CODE to put at location")
- So, if you don't want to use TSB TOOL, you could always just go to location 2411C and start typing 205790 (overwriting the code that's there). Then go to location 248A4 and start typing 207090. Then save the file.
