# Notice

The files in this directory are **index cards**, not mirrors of TecmoBowl.org threads.

- Each card summarizes a linked post and quotes short excerpts (offsets, values, brief explanation).
- Copyright in the original posts, images and attachments remains with their authors.
- The source link on every card points to the full thread; read it there for complete context, images and replies.
- If you are an author and want a card removed or corrected, open an issue in this repository.

The cards were generated in October 2026 from public forum pages. They are provided for reference and interoperability; they are not endorsed by TecmoBowl.org.
